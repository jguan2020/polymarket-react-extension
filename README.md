Polymarket Market Tracker is a Chrome extension that displays trending markets from Polymarket, allows users to favorite markets, and syncs their favorites across devices. It also stores completed markets and their outcomes so users can track how previously favorited markets resolved over time.

Uses React and TypeScript to render market data efficiently and provide a clean, intuitive UI.
Uses AWS Cognito to authenticate users and enable cross-device syncing of favorites.
Uses AWS DynamoDB to store user favorites and completed market outcomes.
Uses AWS API Gateway and AWS Lambda to securely process user requests and integrate with the Polymarket API.
Uses the Polymarket API to fetch real-time market information.
